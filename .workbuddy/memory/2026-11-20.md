## Issue #5 六周疗程、固定起床时间与基线窗口（已完成，issue 已关闭）

- 提交：`780ffb6`（实现）、`f64d843`（两轴评审修正）；分支仍为 `feat/2-offline-pwa-foundation`。
- 领域层 `src/domain/course.ts`：疗程状态只存 `startedOn`、`workPattern`、`wakeTimes[]`；周次/基线延长/窗口全部从日记推导。
- 周次：W1 至少 7 天，近 7 夜 ≥4 完整夜才在次日进入 W2；不足则基线逐日滑动延长，后续周次顺延；W2 起每 7 天一档，W6 结束后为维持期。
- 窗口：W2 用基线 7 夜预览，W3 用锚定周（W2）7 夜重算后启用；W4+ 在 #5 内保持 W3 长度（滴定属 #6）。规则为平均 TST+30 → 15 分钟舍入 → min(平均 TIB) → max(5h)，下限优先并有测试记录。
- 起床时间：近 7 个日历夜的 `outOfBedTime` 中位数预填；确认历史按 `decidedOn` 归属周次 +1 生效，周内改动不移动当前窗口；旧 `preferences.wakeTime` 保留为预填字段（可选），不再在偏好面板编辑。
- 门控顺序：W1 基线 → 筛查未通过 → 轮班 → 未确认起床时间 → 校准数据不足；窗口不可用时仍按最近入睡时间中位数给出 W2 咖啡因截止（basis=recent-bedtime）。
- 持久化：IndexedDB v4 新增 `course` store；`Preferences` 移除必填 `wakeTime`（保留可选旧字段）。
- 界面：`CoursePanel` 提供周轨道、周任务/认知内容、起床时间卡、窗口卡、咖啡因卡、作息类型卡；样式追加在 `style.css` 末尾。
- 测试：56 项全绿。E2E 不再播种 IndexedDB，改用 `page.clock.setFixedTime` + 真实界面操作（开始疗程、筛查、4 晚日记、W2/W3），避免耦合 store 名与真实日期。
- 评审结论：规格侧主要修正了 W4/W5 文案不提前承诺滴定、暂停时仍给咖啡因建议、中位数限定近 7 夜；标准侧移除了测试对 CSS 类名/IndexedDB 表名的依赖，旧偏好起床时间改为预填而非静默丢弃。
- 仍未拆分：`CoursePanel` 仍偏大（状态 + 三张卡 + 周内容），后续可拆为展示组件；`GLOSSARY.md` 已补锚定周/滴定周/巩固周/维持期/咖啡因截止/轮班作息。
