# 本地优先数据架构

本项目采用本地优先的数据架构：睡眠日记与疗程数据默认只保存在用户设备，提供导出/导入作为换机与备份机制，不引入账号和云端同步。睡眠日记属于敏感健康数据；当前目标是移动端 PWA，导出/导入已覆盖首版换机需求，因而本地隐私、离线可用和较小的运维面优先于多端实时同步。

PWA 的安装到主屏幕不改变数据归属：数据仍保存在浏览器的站点存储中。普通刷新、关闭页面和应用更新不应清除数据，但用户清除站点/浏览器数据、使用隐私模式、设备清理存储或更换设备而未迁移时可能丢失记录。因此产品提供压缩迁移包导出与导入，并在首次积累记录后默认提醒备份；提醒可在设置中关闭。`navigator.storage.persist()`只能作为尽力而为的保护，不能替代备份，也不能保证跨设备恢复。
