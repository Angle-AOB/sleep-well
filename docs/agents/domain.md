# Domain Docs

This is a single-context repository for the Sleep Behavior Trainer.

## Before exploring

- Read the root [`GLOSSARY.md`](../../GLOSSARY.md) for canonical domain language.
- Read the relevant decisions in [`docs/adr/`](../adr/) before changing architecture, storage, platform, or clinical safety behavior.
- Read the relevant research notes when a claim depends on evidence or platform behavior.

## Structure

- Domain glossary: `GLOSSARY.md`
- Architecture decisions: `docs/adr/`
- Research notes: `docs/research/`

## Language

Use the canonical terms in `GLOSSARY.md` in issue titles, specs, tests, and implementation notes. If a new concept is needed or a term conflicts with the glossary, resolve the language before changing the model.
